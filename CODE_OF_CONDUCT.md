# Code of conduct

TypoCat follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and remember that contributors write in
many languages. Plain English is fine, and so is imperfect English.

Report unacceptable behavior through the private
[security advisory form](https://github.com/hx-natthawat/typocat/security/advisories/new)
or to a maintainer directly.
